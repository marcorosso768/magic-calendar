## 🦄 Magic Calendar v1.5.1

A smoother update window.

### 🛠️ Fixes
- The update window no longer flickers while downloading: progress is redrawn a few times a second instead of at every piece of data received, and the window is resized only when its content changes

### 🖥️ Platforms
- macOS 13 Ventura or later: Apple Silicon → `Magic-Calendar-1.5.1-mac-arm64.dmg`, Intel → `Magic-Calendar-1.5.1-mac-x64.dmg`
- Windows 10 or later → `Magic-Calendar-1.5.1-win-x64.exe`

### 📦 Notes
If you have version 1.1.0 or later, this update installs itself. The fix shows from the next update onwards: the download is always handled by the version already installed.

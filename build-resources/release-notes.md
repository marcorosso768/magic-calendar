## 🦄 Magic Calendar v1.4.1

A small fix to where the window opens.

### 🛠️ Fixes
- The window now opens centred on the screen you are using, also with several displays
- On smaller screens the window is sized to fit, so it is never cut off by the menu bar or the Dock

### 🖥️ Platforms
- macOS 13 Ventura or later: Apple Silicon → `Magic-Calendar-1.4.1-mac-arm64.dmg`, Intel → `Magic-Calendar-1.4.1-mac-x64.dmg`
- Windows 10 or later → `Magic-Calendar-1.4.1-win-x64.exe`

### 📦 Notes
If you have version 1.1.0 or later, this update installs itself.
